# Eigen-Relational: Spectral Structure of Successor Representations in Transitive Inference

Goal: Build intuition and knowledge around the successor representation (SR) and its spectral structure, using a generic synthetic transitive-inference task.

### In scope
* Generic transitive chain / ring task (transition matrices)
* SR matrix (closed-form + geometric series)
* SVD / eigendecomposition of the SR
* Visualize eigenvectors (show grid-like / spatial-frequency structure)

### Out of Scope (for now)
* Deep linear network training dynamics (this could be a future step)
